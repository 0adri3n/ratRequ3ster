# <p align="center"> ratRequ3ster </p>
<p align="center">一款旨在与 LCU Api (英雄联盟 api) 进行交互的软件</p>


## 安装

前往 <a href="https://github.com/akira-trinity/ratRequ3ster/releases">releases</a> 页面并下载最新版本的 .zip 文件。

解压并启动 ```ratRequ3ster.exe```

您也可以下载源代码并使用 Python 运行（运行前请先下载所需模块！）：
```bash
python ratRequ3ster.py
```

## 使用方法

我想如果您使用我的软件，您应该知道自己在做什么以及在寻找什么。

因此，打开 ratRequ3ster 和英雄联盟，然后确保在此处选择英雄联盟的安装路径：

![image](https://user-images.githubusercontent.com/62818208/224183778-43eccdd4-65b3-4869-9457-e078fc5ac3aa.png)

准备就绪后，前往 <a href="https://www.mingweisamuel.com/lcu-schema/tool/#/">LCU Community 文档</a> 并开始发送 requ3sts！
